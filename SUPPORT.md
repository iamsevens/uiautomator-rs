## Usage Questions

- Prefer GitHub Discussions:
  `https://github.com/iamsevens/uiautomator-rs/discussions`

## Bug Reports

- Use GitHub Issues:
  `https://github.com/iamsevens/uiautomator-rs/issues`
- Please include:
  - OS / Rust / Android versions
  - device or emulator details
  - minimal reproduction steps and logs

## Security Issues

- Follow `SECURITY.md` and use private reporting channels.

## Response Expectations

This is a maintainer-driven open-source project without commercial SLA.
Critical regressions and security issues are prioritized.
