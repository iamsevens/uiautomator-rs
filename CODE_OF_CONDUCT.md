# Code of Conduct

[English](./CODE_OF_CONDUCT.md) | [简体中文](./CODE_OF_CONDUCT.zh-CN.md)

This project is committed to a welcoming, respectful, harassment-free collaboration environment.

## Expected Behavior

- Use respectful and constructive language.
- Focus on technical issues, not personal attacks.
- Accept reasonable feedback and adjust promptly.
- Respect diverse experience levels and viewpoints.

## Unacceptable Behavior

- Insults, discrimination, harassment, threats, or humiliation.
- Repeated personal attacks or deliberate provocation.
- Publishing private information without consent.
- Any behavior that disrupts professional collaboration.

## Scope

Applies to project communication channels, including Issues, Pull Requests, Discussions, and related interactions.

## Enforcement

Maintainers may remove/edit/reject content violating this policy and may limit participation when needed.

If you encounter conduct issues, contact maintainers through repository channels.
For sensitive details, use the private reporting guidance in `SECURITY.md`.
