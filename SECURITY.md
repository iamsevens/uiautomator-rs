# Security Policy

[English](./SECURITY.md) | [简体中文](./SECURITY.zh-CN.md)

## Supported Versions

| Version | Supported |
| --- | --- |
| `main` | Yes |
| latest release | Yes |
| older releases | Best effort |

## Reporting a Vulnerability

Please do not disclose security details in a public issue.

Recommended flow:

1. Use GitHub Private Vulnerability Reporting / Security Advisory.
2. Provide minimum reproducible details: scope, trigger conditions, reproduction steps, impact.
3. If private reporting is unavailable, open a placeholder issue (for example `Security report request`) without details; maintainers will provide a private channel.

## Response Targets

- Acknowledgement within 48 hours (business days).
- Initial triage within 7 days (severity and remediation plan).
- Public release note credit after fix if reporter agrees.

## Scope

This policy covers:

- `uiautomator/`
- `uiautomator-cli/`
- release workflow and CI configuration
