## [未发布]

### 修复（ATX 环境可靠性）
- 解决 ATX-Agent 在模拟器/不同 ABI 设备上的误判与不稳定问题：
  - `build.rs` 支持多架构资源嵌入（`armv7/arm64/386/legacy`，含 `amd64` 资源位）。
  - 安装时按设备 ABI 选择并校验匹配二进制，避免错误架构导致“进程存在但服务不可用”。
  - `/version` 健康检查使用短超时探测，`check_atx_agent_status` 改为“HTTP 健康优先、进程状态仅作诊断”。
  - 启动流程改为先清理旧进程再启动，降低残留进程导致的假阳性。
  - APK 安装移除易超时的预检查分支，减少 `pm` 查询阻塞导致的安装流程卡死。

### 修复
- 🐛 **[P0] 修复 Selector mask 字段缺失问题** (2026-02-19)
  - 添加 14 个字段的 mask 常量定义
  - 在 `to_params()` 方法中自动计算 mask 字段
  - mask 值与 Python UIAutomator2 完全一致
  - 修复后所有选择器功能恢复正常
  - 添加完整的 mask 计算测试（单字段、多字段组合）
  - 添加验证示例 `examples/test_mask_fix.rs`

- 🐛 **[P1] 修复 ATX-Agent 误判与 UiObject 错误映射问题** (2026-02-25)
  - 修复 ADB `shell_v2` 输出解析，避免 `atx-agent version` 输出被错误解码导致“未安装”误判
  - `ATX-Agent /version` 兼容 JSON 与纯文本响应（如 `0.10.0`）
  - 收紧 `UiObject` 的元素未找到错误映射规则，减少把 selector 语法错误误判为 `ElementNotFound`
  - `UiObject::set_text` / `clear_text` 统一 JSON-RPC 错误处理并校验动作返回值（`false` 视为失败）
  - `Device::app_start` 改为按关键失败行判错，并截断错误详情，避免 `contains("Error")` 类误报
  - 已在模拟器上完成 ignored 全量回归：`uiautomator-cli` 与 `uiautomator` 均通过

## 版本说明

### 版本号格式

版本号格式为 `主版本号.次版本号.修订号`：

- **主版本号**: 不兼容的 API 变更
- **次版本号**: 向后兼容的功能新增
- **修订号**: 向后兼容的问题修正

### 变更类型

- `新增`: 新功能
- `变更`: 现有功能的变更
- `弃用`: 即将移除的功能
- `移除`: 已移除的功能
- `修复`: 问题修复
- `安全`: 安全相关的修复
